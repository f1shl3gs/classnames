# classnames

This lib is a very simple and lightweight library, after minify it only 0.22kB

## Usage

```json
{
  "dependencies": {
    "classnames": "github:f1shl3gs/classnames#v1.0.0"
  }
}
```

## What's the price?

The Argument doesn't support array and nested structure, but it's totally fine for 99% users

```typescript
export type Argument = string | null | undefined | Record<string, unknown>
```
